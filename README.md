Senior Quality Engineer with **13+ years** in quality assurance and **10 years** of hands-on test automation, building automation frameworks and quality strategies for **fintech, banking, government and iGaming** platforms. I enjoy backend/API testing, event-driven and distributed systems (Kafka, AWS, Kubernetes), and building CI/CD quality gates that let teams ship with confidence.

- 🔭 Open to **Senior QA Automation Engineer / SDET / Quality Engineer / QA Lead** roles: remote across the EU, or relocation

- 💬 Ask me about Java test frameworks, Kafka and event-driven testing, API testing (RestAssured, Karate) or CI/CD quality gates

### ⭐ Highlights

- **Event-driven test frameworks:** Spring Boot-based Java harnesses validating Kafka and AWS SQS/SNS message flows and their transformation into MongoDB, RDS and DynamoDB
- **CI/CD quality gates:** authored `gitlab-ci.yml` for staged runs (dev, pre-production), with failing tests blocking the deploy and a risk-based stage subset so hotfixes are not stuck behind long suites
- **Migration validation:** proved a legacy monolith's replacement by requiring identical draw evaluations and payouts in both systems, catching accuracy before release
- **Legacy core banking:** built the first automation framework for a bank's legacy core system, replacing a fully manual regression
- **Test leadership:** Test Lead on regulatory deliveries for credit and fraud-risk systems, and automation coach for teams adopting automated testing
